WINDOWS

See which apps on your Windows PC send your data, and where

WhoSees is a free, open-source network monitor made for everyone: it shows which app is sending data, which company receives it and where in the world it goes, live on a map, in plain English.

Download for Windows ↓

What you'll see

  • Which app is sending data, by its real name.
  • Which company receives it: Google, Meta, Amazon, or an advertising or analytics firm you've never heard of. Trackers and advertisers are labelled.
  • Where in the world it goes, drawn live on a map from wherever you are.
  • What kind of data it probably is, like your location or advertising ID, plus a privacy report for each app.
  • Warnings when an app connects to a known scam website or malware server.

How to install WhoSees on Windows

  1. Click Download for Windows to get WhoSees-Windows-Setup.exe (about 190 MB).
  2. Run the installer. Windows shows a blue "Windows protected your PC" screen: click More info, then Run anyway.
  3. Choose where to install it and click Install.
  4. Open WhoSees from the Start menu and click Start live view.
WHY WINDOWS WARNS YOU

Windows shows that warning for any new program that isn't code-signed yet, meaning it doesn't carry a digital signature proving who published it. It doesn't mean anything is wrong with WhoSees. WhoSees has applied for free code signing from the SignPath Foundation; once approved, the installer will be signed and the warning fades as more people install it.

Standard and Deep mode

MODEWHAT IT DOES
StandardNo administrator rights needed. Shows apps, companies and places from Windows' own connection list.
DeepAsks Windows for permission (a Yes/No prompt) each time you press Start. Adds website names and catches every connection, even ones that last a split second. Still only reads where data goes, never what's inside it.

Check your download

The Windows installer is built automatically by GitHub from the public source code, never on a personal computer. To confirm your copy wasn't changed, open PowerShell in your Downloads folder and run Get-FileHash WhoSees-Windows-Setup.exe, then compare the result with SHA256SUMS.txt.

Uninstalling

Settings → Apps → Installed apps → WhoSees → Uninstall. Nothing keeps running after you close WhoSees.

Questions

Why does Windows say 'Windows protected your PC'?

Windows shows this for new programs that aren't code-signed yet. It doesn't mean anything is wrong with WhoSees. Click More info, then Run anyway. WhoSees has applied for free code signing from the SignPath Foundation.

Is WhoSees a firewall?

Not in this version. WhoSees shows which apps connect where; blocking is built but switched off for now.

Does WhoSees read my traffic?

It reads where your data goes, never what's inside it. Almost all traffic is encrypted, and WhoSees doesn't open it.
